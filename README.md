# cuda-codegen-on-a-real-gpu-from-loop-ir-to-tensor-cores
Weeks seven and eight of the 'Compilers for Machine Learning' syllabus, on a real Tesla T4. Build a small loop IR with thread indices, shared memory and accumulators, render it to CUDA with a C-style expression renderer, compile the text with nvcc and run it through ctypes on PyTorch tensors.
